# EndeavorOS_config

Kişisel EndeavorOS / Hyprland rice yapılandırma dosyalarım.

## İçerik
- `hypr/` — Hyprland (Lua config) ve autostart
- `waybar/` — Waybar konfigürasyonu, çok monitörlü auto-hide scripti
- `kitty/`, `fish/`, `zsh/` — terminal/shell
- `rofi/`, `rofi.safak/` — launcher temaları
- `eww/`, `dunst/`, `swaync/`, `swayosd/` — widget/bildirim
- `fuzzel/`, `wofi/`, `wlogout/` — menüler
- `mpv/`, `btop/`, `cava/`, `fastfetch/` — diğer araçlar
- `wallust/`, `matugen/` — renk şeması üretimi
- `gtk-3.0/`, `gtk-4.0/` — GTK temaları

Tarayıcı profilleri, mail, IDE durumu, oyun launcher cache gibi hassas/büyük
klasörler bu repoya dahil edilmemiştir (bkz. `.gitignore`).
